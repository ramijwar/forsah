# فرصة — لوحة الإدارة وPHP/SQLite API

## المتطلبات

- PHP 8.1 أو أحدث مع `pdo_sqlite` و`mbstring`.
- Node.js 22.12+ لبناء الواجهة.
- تنشأ قاعدة SQLite تلقائيًا في `var/forsah.sqlite` خارج جذر الويب عند أول طلب، مع صلاحيات نظام ملفات مقيدة؛ يمكن نقلها بمتغير `FORSAH_DB_PATH`.

## تشغيل محلي

من جذر المشروع:

```bash
cp .env.example .env
# غيّر VITE_API_BASE_URL إلى خادم التطوير؛ المثال يشير إلى الإنتاج
npm run dev
```

في طرفية ثانية:

```bash
php -S 127.0.0.1:8000 -t backend
```

افتح `http://localhost:5173/#/admin` للوصول إلى صفحة الدخول الإدارية. ويمكنك زيارة `/#/messages` لإرسال تذكرة دعم جديدة.

## إنشاء أول حساب Super Admin

شغّل أداة الإعداد مرة واحدة على قاعدة البيانات المقصودة:

```bash
php backend/bootstrap-admin.php
```

تطلب الأداة الاسم والبريد وكلمة مرور قوية لا تقل عن 6 أحرف؛ لا تطبع كلمة المرور ولا تخزنها كنص صريح. ترفض إنشاء أي حساب إداري إذا كان موجودًا بالفعل، ولا توجد بيانات دخول افتراضية. للأتمتة تتوفر متغيرات اختيارية `FORSAH_ADMIN_NAME` و`FORSAH_ADMIN_EMAIL` و`FORSAH_ADMIN_PASSWORD`؛ لا تضع الأسرار في المستودع أو سجل الأوامر. أوقف/احذف أداة bootstrap بعد تهيئة الإنتاج وفق إجراءاتك.

إعدادات إضافية: `FORSAH_DB_PATH` لمسار القاعدة، و`FORSAH_CORS_ORIGINS` لقائمة origins مفصولة بفواصل (اضبط نطاق الويب الفعلي في الإنتاج؛ القيمة الافتراضية `https://t3lam.site,https://localhost` للويب وCapacitor Android). يمكن تمرير `FORSAH_IP_HASH_SALT` لتجزئة عناوين IP بسَلط نشر خاص.

## المصادقة والأدوار

- `POST ?resource=admin&action=login` يعيد رمز Bearer عشوائيًا opaque بصلاحية 12 ساعة. لا يخزن الخادم سوى SHA-256 للرمز؛ تحتفظ الواجهة به في `sessionStorage` وتبطل الجلسة عند تسجيل الخروج.
- حد الدخول 10 محاولات لكل عنوان IP خلال 15 دقيقة، مع حدود منفصلة لإرسال الإعلانات ورسائل الدعم والبلاغات. جميع نقاط الإدارة الأخرى تتحقق في الخادم من الرمز، ومدة صلاحيته، والدور، وحالة الحظر.
- الأدوار: `super_admin`, `admin`, `support`, `user`. يستطيع الدعم إدارة المحتوى والبلاغات، وتعديل/حظر المستخدمين العاديين، ومتابعة التذاكر؛ لا يمكنه تغيير حسابات الإدارة أو الأدوار. المدير يستطيع إدارة موارد المنصة. المدير الفائق وحده يستطيع تغيير أدوار الحسابات إلى `admin` أو `support` أو `user` من الواجهة؛ إنشاء المدير الفائق يتم بأداة bootstrap فقط ولا يمكن ترقية الحسابات إلى هذا الدور عبر API.
- كلمات المرور تستخدم `password_hash`، واستعلامات SQLite مهيأة، ومفاتيح العلاقات الأجنبية مفعّلة، وكل تغييرات الإدارة تسجل في `admin_audit_log`.

## الوظائف والجداول

الجداول الأساسية: `users` و`sessions` و`ads` و`reports` و`support_tickets` و`ticket_messages` و`admin_audit_log` و`login_attempts` و`public_rate_limits`. إعلانات الجمهور الجديدة تحفظ بحالة `pending` ولا تصبح نشطة إلا بعد اعتماد إداري. التذاكر الواردة من نموذج الرسائل تصل مباشرة إلى تبويب الدعم. البلاغات يمكن تقديمها إلى endpoint الموضح أدناه وتظهر في تبويب «إدارة البلاغات»؛ تتوفر الآن واجهة بلاغات من صفحة الإعلان للمستخدم المسجل. تخضع عمليات الدخول والطلبات العامة لتحديد المعدل. قاعدة البيانات الافتراضية في `var/` خارج مجلد `backend` الذي يشغّله خادم PHP، وملفها ينشأ بوضع `0600`.

## نقاط API

الاستجابات JSON بشكل `{ "ok": true, "data": ... }` أو `{ "ok": false, "error": ... }`.

| الطلب | الصلاحية | الغرض |
|---|---|---|
| `POST ?resource=admin&action=login` | عام + حد محاولات | دخول الإدارة |
| `GET ?resource=admin&action=me` | إدارة | هوية الجلسة |
| `GET ?resource=admin&action=stats` | إدارة | عدادات المستخدمين والإعلانات والبلاغات والتذاكر |
| `GET ?resource=admin&action=ads` | إدارة | قائمة الإعلانات |
| `PATCH/DELETE ?resource=admin&action=ad&id=…` | إدارة | تعديل/اعتماد/حظر/حذف إعلان |
| `GET ?resource=admin&action=users` | إدارة | قائمة المستخدمين |
| `PATCH ?resource=admin&action=user&id=…` | إدارة | تعديل البيانات أو حظر/فك الحظر؛ تعيين الأدوار لـ `super_admin` |
| `GET ?resource=admin&action=reports` | إدارة | قائمة البلاغات |
| `PATCH ?resource=admin&action=report&id=…` | إدارة | إغلاق البلاغ بعد التعامل أو صرف النظر |
| `GET ?resource=admin&action=tickets` | إدارة | قائمة التذاكر |
| `GET/PATCH ?resource=admin&action=ticket&id=…` | إدارة | عرض الرسائل أو تحديث الحالة |
| `POST ?resource=admin&action=ticket-reply&id=…` | إدارة | الرد على تذكرة |
| `POST ?resource=admin&action=logout` | إدارة | إبطال الجلسة |
| `POST ?resource=support&action=tickets` | عام | استقبال رسالة دعم من نموذج التطبيق |
| `POST ?resource=reports&action=create` | عام | تسجيل بلاغ على إعلان أو حساب |
| `GET ?resource=services` | عام | الفئات المتوافقة مع واجهة المستخدم |
| `POST ?resource=ads` | عام | إرسال إعلان إلى قائمة المراجعة |

## الاختبارات

```bash
npm run build
php -l backend/api.php
php -l backend/bootstrap-admin.php
python3 backend/tests/smoke.py
```

ينشئ الاختبار قاعدة بيانات مؤقتة وحسابات اختبار، ويشغل خادم PHP محليًا، ثم يتحقق من إنشاء المدير ورفض المدير المكرر، ومنع الوصول بلا جلسة أو بدور مستخدم عادي، وتسجيل الدخول كمدير ودعم، ومراجعة إعلان وبلاغ، والرد على تذكرة، وحظر المستخدم وفك الحظر، ومنع الدعم من تعديل الأدوار، وإبطال رمز الخروج، وسجل التدقيق. تُحذف قاعدة الاختبار تلقائيًا عند الانتهاء.
